# @ai-changeguard/replay

Replays real prompts on an old and a new AI model and reports what changed.

Part of [AI Change Guard](https://github.com/Navin-kumar0007/ai-change-guard-cli). To use the command-line tool, run `npx ai-change-guard`; see the [ai-change-guard](https://www.npmjs.com/package/ai-change-guard) package.
